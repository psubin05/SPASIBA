# 가짜 Pi 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 인터페이스 v0.3 2장 형식으로 event·status·crop을 발행하고 crop_request에 자동 응답하는 가짜 Pi와 시나리오 8개를 만든다.

**Architecture:** 메시지 생성·검사는 순수 함수(`tools/fake_pi_messages.py`), 시나리오 읽기·검사는 `tools/scenario.py`, MQTT 실행은 `tools/fake_pi.py`. 시나리오는 `tools/scenarios/*.json`.

**Tech Stack:** Python 3.12+, paho-mqtt 2.x (`CallbackAPIVersion.VERSION2`), pytest. 새 패키지 없음.

**Spec:** `docs/specs/2026-11-15-fake-pi-design.md`, `../docs/server_interface.md` (1장, 2장)

## Global Constraints

- 토픽: `spasiba/{zone_id}/{camera_id}/event|status|crop_request|crop`, QoS 1, JSON UTF-8 (`ensure_ascii=False`)
- event 필수: `event_id`(UUID v4), `plate_number`, `camera_id`, `zone_id`, `slot_id`, `recognized_at`(ISO 8601 +09:00). 선택: `votes`, `frames`, `kind`(기본 `confirm`)
- status: 연결 시 `{"state":"online","ts":…}` retained, LWT `{"state":"offline"}` retained
- crop: `request_id`, `slot_id`, `event_id`, `captured_at`, `image_jpeg_base64`; JPEG ≤ 100KB, 실제 번호판 사진 금지
- 번호 형식: `^(서울|부산|대구|인천|광주|대전|울산|세종|경기|강원|충북|충남|전북|전남|경북|경남|제주)?\d{2,3}[가-힣]\d{4}$`
- 이 폴더는 아직 git 저장소가 아니다 → 커밋 단계 없음. 각 작업 끝에 `.venv/bin/python -m pytest -q` 전체 통과.

## Review Focus

1. 지역명 번호(`서울12가3456`)와 3자리 번호(`123가4567`)가 유효로 판정돼야 한다 → Task 1 테스트
2. `repeat_of`가 없는 `event_ref`를 가리키면 실행 전에 시나리오 오류로 멈춰야 한다 → Task 2 테스트
3. 잘못된 JSON이나 모르는 slot의 crop_request가 와도 가짜 Pi가 죽지 않고 경고만 → Task 3 테스트
4. 브로커에 연결 못 하면 무한 대기하지 않고 5초 안에 오류 종료 → Task 3 테스트
5. `disconnect abrupt`는 LWT(offline)가 나가도록 소켓을 끊어야 한다 (정상 종료는 직접 offline 발행) → Task 3 통합 테스트

### Task 3: 실행기 `fake_pi.py`

**Files:** Create `tools/fake_pi.py`; Test `tests/test_fake_pi.py`

**Consumes:** Task 1 전부, `load_scenario`
**Produces:**
- `class FakePi` — `__init__(self, scenario: dict, *, host="localhost", port=1883, username=None, password=None, tls=False, connect_timeout=5.0, publish=None)`; `publish`를 주면 MQTT 대신 `publish(topic, payload_dict, retain)` 호출 (테스트용)
- `FakePi.handle_crop_request(camera_id: str, raw: bytes) -> dict | None` — JSON 오류·모르는 slot이면 경고 로그 후 None, 정상이면 crop을 발행하고 payload 반환. slot의 최근 event_id가 없으면 요청의 event_id 사용
- `FakePi.run(linger: float = 2.0) -> list[dict]` — 연결(카메라별 client_id `fake-{camera_id}`, LWT 설정, online retained) → steps 실행 → `linger`초 동안 crop_request 대기 → 남은 카메라 정상 종료(offline 발행 후 disconnect). 발행한 메시지 기록 `[{"topic","payload","retain"}]` 반환
- `main(argv: list[str] | None = None) -> int` — `python -m tools.fake_pi SCENARIO [--host --port --username --password --tls --linger --entries-url]`; 출력은 발행할 때마다 한 줄 (`→ topic plate`). `--entries-url`이면 entries를 POST하고 501/연결 실패는 경고만
- 연결 실패: `connect_timeout` 안에 on_connect 없으면 `ConnectionError` → main은 메시지 출력 후 종료 코드 2
- abrupt disconnect: DISCONNECT 패킷 없이 `client.loop_stop(); client.socket().close()` → 브로커가 LWT(offline) 발행

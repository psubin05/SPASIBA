# 현재 상태와 남은 작업

> 아래는 통합 전 기록이다. server/matching에서 실제 수인 코드 연결을 완료했으며
> 현재 실행·검증 범위는 [통합 문서](integration_matching.md)를 우선한다.

기준: server_interface v0.3.1. 우드락 제작은 사용자 요청으로 보류한다.
카메라는 A열/B열별 기존 임시 배치를 유지한다.

## 로컬에서 완료·검증한 부분

- QR→출발 노드, 지도 JSON, Dijkstra·안내문·경로 API.
- 3D/평면, 이동 재생·정지·재개, 차량 검색 후 경로 연결.
- 임시 어댑터를 이용한 입차→위치 확인→매칭→차량 검색→경로→출차 흐름.
- 한글 원문·실제 HTTP 인코딩 검증, 중복·역순 이벤트 및 병렬 입차 테스트.
- 지도 DB 스키마·검토 가능한 적재 SQL 생성.

## 이번 보강

- 시각 정밀도가 다른 동일 시각을 문자열이 아닌 실제 시각으로 비교.
- 이전/충돌 관측이 최신 위치를 덮어쓰는 것을 차단.
- 지도가 바뀌어 저장된 주차면이 사라진 경우 500 대신 PENDING.
- 동시에 같은 번호로 입차 요청해도 ACTIVE 세션 하나만 생성.
- 입차·관측·출차 중 중복 조작과 검색을 잠그고 종료 시 이전 경로 초기화.
- 8초 요청 제한, 비 JSON/잘못된 경로 응답 처리, 오래된 검색 응답 무시.
- HTTP 캐시 비활성화, 저장소 일시 장애에 공통 503 오류 제공.
- 미래 30초를 넘는 관측·입차를 로컬 시연에서 차단. 이 제한은 명세의
  확정 규칙이 아닌 시연용 시간 오류 방어이며 실물 연동 시 시계 설정과 함께 검토한다.

## 외부 자료·환경이 필요한 부분

| 작업 | 필요한 것 |
|---|---|
| 수인 정식 백엔드 연결 | 실제 코드/실행 주소, 라우터·DB 연결 방식 |
| 공용 PostgreSQL 적용·검증 | 테스트 DB 접속 환경, 현재 스키마 |
| 실제 입구·주차면 이벤트 연결 | 차단기/Pi OCR 출력, MQTT 계정·TLS 설정 |
| QR 이미지 생성과 휴대폰 스캔 | 시연 서버 접속 주소 결정 |
| 실측 지도·ROI | 배치 확정·실물 카메라 영상 (제작 단계에서 진행) |

실제 브라우저의 시각·마우스 조작 검증도 남아 있다. 현재 자동 화면 테스트는
DOM/Canvas 대역에서 동작하며 픽셀 렌더링·다운로드·모바일 브라우저를 보장하지 않는다.
기존 브라우저 도구는 URL을 확인하지 못해 중단된 상태다.

로컬 어댑터의 테스트 통과를 수인 정식 서버·MQTT·PostgreSQL 통합 완료로 보지 않는다.
정식 데이터의 시간·지연·경합 특성을 확인한 뒤 같은 시나리오로 재검증한다.

# 1차 구현 검증 (2026-11-17)

- `python -m unittest discover -s tests -v`: 8개 통과.
- 14개 노드의 모든 쌍(196조합)에서 직접 구현 Dijkstra 최단거리를 NetworkX와 비교.
- 샘플 QR 1개와 주차면 8개 조합의 경로 API 응답 확인.
- 샘플 A-03 경로: 16m, 15m 직진 후 좌회전, 1m 직진, 도착.
- QR·지도·경로 응답 필드, 잘못된 ID 및 누락 파라미터의 공통 오류 형식 검증.
- 지도: 14 nodes / 13 edges / 8 slots, 등록 관계·연결성 검증 통과.
- Node `--check`로 시뮬레이터 JavaScript 문법 검사 통과.

## 응답 시간

실행 중인 Uvicorn의 localhost HTTP `/route`를 5회 예열 후 100회 측정했다.
샘플 출발 `QR-B2-ENT1`, 도착 `B2-A-03` 기준이다.

| 항목 | ms |
|---|---:|
| 평균 | 11.685 |
| 중앙값 | 5.349 |
| p95 | 30.366 |
| 최대 | 33.283 |

이 실행에서는 50ms 기준 이내였다. 실제 모형·배포 네트워크 성능을 보장하는 수치는 아니다.
재측정: `python -m tools.benchmark_route`.

## 남은 검증

브라우저 접근 호스트가 연결되지 않았고, Windows Chrome 창의 상태 조회도
최소화 상태 오류로 실패해 시뮬레이터의 화면과 이동 재생을 직접 조작해 확인하지 못했다.
HTML 제공과 JavaScript 문법은 확인했지만 브라우저 런타임·시각 검증은 남아 있다.
실제 모형 도면, 카메라 ROI, PostgreSQL, 차량 매칭 서버 연동은 아직 미검증이다.

## 3D 업데이트 검증

이전 1차 수치와 구분한 현재 결과:

- Python 테스트 13개 통과: API 계약, 196쌍 최단거리, 좌/우 안내,
  잘못된 주차면/카메라 배치·중복 간선 검출, SQL 생성/문자열 처리.
- Node 스크립트 테스트 통과: 유한한 3D 투영 좌표, 경로 표시,
  재생·일시정지·재개·도착, 주차면 변경 시 경로 초기화, 2D/3D 전환,
  110×40cm 및 88×32cm 치수 환산, 잘못된 제작 크기 차단.
- Node 테스트는 실제 브라우저가 아닌 DOM/Canvas 대역으로 실행한다.
- 브라우저 호스트 연결 실패 후 새 Chrome 창으로 재시도했으나 도구가 현재 URL을
  확인하지 못해 중단했다. 실제 화면·다운로드·마우스 조작 검증은 남아 있다.
- PostgreSQL 설치/psql/Docker가 현재 PATH에 없어 스키마 실제 적용을 수행하지 않았다.
  생성 SQL과 JSON 대응 검증은 했으나 PostgreSQL 실행 검증과는 별개다.

반복 실행: `python -m tools.verify` (Python 환경 패키지와 Node.js 필요).

## 입차·QR 검색 흐름 업데이트

- Python 테스트 총 20개 통과.
- 임시 SQLite DB에서 입차→PENDING→관측 매칭→CONFIRMED→QR 경로→출차 404→재입차 검증.
- 앱 재생성 후 기록 유지, 번호 정규화, 중복 입차/이벤트, 잘못된 카메라 관계,
  고유 EDIT1과 모호한 후보, 같은 칸 차량 교체와 다른 칸 이동 검증.
- 지도 전용 앱에서는 시연용 입차 API가 활성화되지 않는 것을 확인.
- Node 화면 코드 테스트에서 PENDING/404는 route 요청을 하지 않고,
  CONFIRMED만 응답의 slot_id로 route를 요청하는 것을 확인.
- 실제 QR 스캔·카메라 입력·브라우저 시각 검증은 아직 포함되지 않는다.

## 오류 상황 보강 검증

- 최신 Python 테스트 29개 통과.
- 실제 SQLite에서 병렬 입차 8건 중 1건만 생성, 나머지 7건은 409.
- 시각 정밀도 차이, 이전/동일 시각 충돌 관측, 미래 관측, votes 누락 검증.
- 지도에서 사라진 주차면은 PENDING, 저장소 장애는 공통 503 응답 확인.
- 캐시 방지 헤더 및 한글 회귀 테스트 유지.
- Node 테스트에 지연된 검색 결과 무시, 빈 경로/잘못된 JSON, 시간초과 오류 복구 추가.
- 임시 시연 어댑터에만 적용된 시간·저장 방어와 정식 수인 구현은 구분한다.
- 설치 재현용 requirements-lock.txt 생성. 새 환경 재설치 자체는 별도 검증 전이다.
